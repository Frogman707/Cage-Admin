# Card faces

The 52 rank faces are rasterized from **Vectorized Playing Cards** by Chris Aguilar,
by way of the hand-optimized SVG build in
[digitaldesignlabs/responsive-playing-cards](https://github.com/digitaldesignlabs/responsive-playing-cards).
The ace of spades in that deck comes from Byron Knoll's public-domain cards.

**License: LGPL 3.0** — see https://www.gnu.org/licenses/lgpl-3.0.html. The artwork is
used unmodified (rasterized and scaled only), so the obligation is to keep this notice
and to leave the original SVGs obtainable at the link above. If a licence with no
obligations at all is ever wanted here, Byron Knoll's deck
(https://code.google.com/archive/p/vector-playing-cards/) is public domain and drops in
the same way — it is what this folder held previously.

Rendered to PNG at 300x419 through headless Chromium. The source art is 225:314, true
poker proportions (2.5 x 3.5in), and square-cornered, so the rounded corner is added at
render time and the artwork clipped to it. Palette-quantized to 128 colours: the deck
weighs 449 KB instead of 1.6 MB.

`card_back.png` is not from that deck; it is drawn for this site in the AVATAR SPEED
navy/brass palette, on the same silhouette so backs and faces line up.
