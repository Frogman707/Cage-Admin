# 12 — CI · 골든 테스트 (Verification Harness)

> **마일스톤**: **M0 — 이 항목이 M0의 첫 커밋이다** · **선행**: 없음 · **후행**: 전부
> **입력**: [`10-acceptance-criteria.md`](../architecture/10-acceptance-criteria.md) §3 `DR-12` · [`ddl/README.md`](../architecture/ddl/README.md)
> **닫는 수용 기준**: `AC-12-1` ~ `AC-12-6` · `AC-49-*` · `AC-72-*`

---

## 1. 왜 이것이 먼저인가

아홉 회차가 잡은 결함 중 상당수는 **골든 테스트 한 벌이면 사람이 문서를 읽기 전에 드러났다** — `DR-01`(마감 불가) · `DR-02`(동결 불가) · `DR-04`(23505) · `DR-06`·`DR-08`(`no_data_found`) · `DR-11`(누계 오염) · `DR-39`(승인 미발동).

2026-08-15에 PostgreSQL 18.6 컨테이너로 적용·동작 검증을 1회 수행했다. **그것은 사람이 손으로 돌린 것이고 CI가 아니다.** 이 스펙은 그 검증을 자동화한다.

## 2. 파이프라인 요구사항

| ID | 요구사항 | AC |
|---|---|---|
| `R-12-01` | CI에 PostgreSQL 18 서비스 컨테이너가 있고 `ddl/0*.sql`을 순차 적용하는 잡이 **모든 PR에서** 돈다. 적용 실패는 머지를 막는다 | `AC-12-1` |
| `R-12-02` | **분개 계약 테스트** — [`04-posting-rules.md`](../architecture/04-posting-rules.md)의 각 절마다 테스트가 하나씩 있다. `op_*`를 호출하고 `ledger.entries`의 `(account_kind, sign, category)` 집합을 그 절의 표와 **정확히** 비교한다. **절 하나에 테스트가 없으면 잡이 실패한다** | `AC-12-2` |
| `R-12-03` | **불변식 테스트** — I1~I8 각각에 "위반 시도 → 예외" 테스트가 최소 1건. 예외 없이 통과하면 실패로 처리한다 | `AC-12-3` |
| `R-12-04` | **전 경로 시나리오** 4종 — ① 개설→바이인→롤링→중간정산→종료→마감 ② 개설→취소 ③ 실사 차액→해소→마감 ④ 커미션 정산→역분개. 각 종료 시 `ledger.v_integrity_status`의 **모든 행이 `violations = 0`** | `AC-12-4` |
| `R-12-05` | **드리프트 검사** — 매 실행 끝에 `ledger.v_check_view_security`와 `ledger.v_check_public_execute`가 각각 0행 | `AC-12-5` |
| `R-12-06` | **CI 잡이 조용히 건너뛰지 않는다.** 경로 필터·조건부 실행으로 스킵되면 그 사실이 머지 차단 신호가 된다 | `AC-12-6` |

> `AC-12-6`의 근거는 실제 사고다 — [`07` §7](../architecture/07-migration.md)이 기록한 Track A 인시던트에서 경로 필터 누락으로 `firestore.rules` 변경이 배포되지 않았다.

**보조 검증**

```sql
-- 문서·표·함수 셋이 같은 표를 표현하는지 기계 대조 (AC-12-2 보조)
SELECT kind, category, account_kind, sign FROM ledger.posting_rules ORDER BY 1,2,3,4;
-- 이 결과와 04 의 표를 테스트가 대조한다. 사람이 눈으로 보지 않는다.
```

`04`의 첫 줄이 **"이 표가 구현 계약이다"** 라고 선언한다. `AC-12-2`가 없으면 그 문장은 검증되지 않는 주장이다.

## 5. 테스트 데이터 규약

U1=데모 결정으로 **이관 데이터가 없다.** 테스트 픽스처를 처음부터 만든다.

| ID | 요구사항 |
|---|---|
| `R-12-20` | 픽스처가 `ledger.provision_branch()`로 지점을 만든다. 수동 INSERT로 반쪽 지점을 만들지 않는다 |
| `R-12-21` | 통화 5종 각각에 대해 최소 한 시나리오가 돈다 — **PHP만 통과하고 나머지가 비뚤어지는 사각**(`DR-41`)을 CI가 잡는다 |
| `R-12-22` | KRW(`minor_unit = 0`) 금액 표기 테스트가 있다 |
| `R-12-23` | 픽스처에 개인정보·실계좌 값을 쓰지 않는다 |

## 6. 열린 항목

- CI 실행 시간 예산. 시나리오 4종 × 통화 5종이 커지면 **통화 매트릭스를 nightly로 분리**하고 PR에서는 PHP + 1종만 돌린다. 그 분리를 하면 `AC-12-6`의 "조용히 건너뛰지 않는다"가 nightly에도 적용돼야 한다.
